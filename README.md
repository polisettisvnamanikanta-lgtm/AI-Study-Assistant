
# AI Study Assistant 📚

An AI-powered study assistant built using Python, Google Gemini API and Streamlit.

## Features

- Ask academic questions.
- Get AI-generated explanations.
- Understand difficult concepts in simple language.
- Upload PowerPoint presentations.
- Get slide-by-slide explanations and summaries.

## Technologies Used

- Python
- Google Gemini API
- Streamlit
- python-pptx (if used in your implementation)

## Installation

Clone the repository:

git clone https://github.com/polisettisvnamanikanta-lgtm/AI-Study-Assistant.git

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## API Configuration

Configure your Gemini API key using Streamlit secrets.

Never expose your API key publicly.
